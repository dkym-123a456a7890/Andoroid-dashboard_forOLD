# スマートダッシュボード (Smart Dashboard for Android)

旧型Android端末やタブレットを、リビングやデスクで常時稼働できる**スマートディスプレイ**として生まれ変わらせるダッシュボードアプリです。

Google AI Studio Build & Jetpack Compose (Material Design 3) で開発されています。

---

## 📱 主な機能

- **🕒 時計・日付表示**: 大きなデジタル時計、和暦（令和）、秒数表示、ネット接続状態インジケーター
- **☀️ 天気予報 (Open-Meteo API)**: 滋賀県近江八幡市（全国各地へ切り替え可能）の現在天気、気温、体感温度、降水量、風速、週間天気予報
- **📰 ニュース速報 (自動スクロール)**: 最新の主要・地域ニュースをティッカー風に自動アニメーション巡回。手動操作時は自動停止＆7秒後に自動再開
- **🔥 X (Twitter) トレンド**: 今日本で話題のキーワードを一覧表示（ワンタップで詳細検索QRコード生成）
- **🎉 今日は何の日 (記念日)**: 365日の記念日や歴史的トピックを表示
- **📅 予定・カレンダー & ToDo**: 月間カレンダー表示と日々のタスク管理
- **🚀 アプリランチャー (左スワイプ)**: 端末内のインストール済みアプリを一覧表示・クイック起動（フォルダ整理・非表示対応）
- **⏱️ タイマー・アラーム & 🤖 AIアシスタント (右スワイプ)**:
  - 複数タイマー（長押し連続増減対応）
  - 目覚ましアラーム機能
  - Gemini AI を活用したAIノート・アシスタント（便利機能ドロワー内へ統合）
- **🔄 GitHub Releases 自動アップデート**:
  - GitHub Releases と直接連携し、アプリ内からワンタップで最新版へ自己アップデート
  - 古いAndroid端末でもSSL/TLSエラー（CertPathValidatorException）を起こさないレガシー通信対策済み
  - ブラウザからの直接ダウンロードにも対応

## 🚀 最新バージョン: v1.2 の更新内容

### 🏷️ v1.2 (2026-10)
- **🔒 旧型端末向けSSL/TLS通信エラーの修正**:
  - 古いAndroid端末（Android 5〜7系）でGitHubのCDN（AWS S3）からAPKをダウンロードする際に発生していた `CertPathValidatorException: Trust anchor for certification path not found` を解消。
  - レガシーTLS 1.2ソケットファクトリとカスタムTrustManagerを実装し、旧端末でもアプリ内から直接アップデートできるよう修正。
  - 更新ダイアログに「ブラウザで直接APKをダウンロード」するフォールバック機能を追加。
- **📺 横画面専用（Landscape）固定化**:
  - スマートディスプレイとしての視認性を最大化するため、画面を横向きに固定。
  - 横向きスマートフォンでも表示崩れが起きないよう、パディング・文字サイズ・引き出しメニュー幅を動的自動最適化。
- **📜 ニュースの自動巡回スクロール機能**:
  - センターパネルのニュース一覧が約3.8秒ごとに自動スクロール。手動閲覧検知とステータス表示に対応。
- **🤖 AIアシスタントの配置見直し**:
  - センターパネルを常時情報（ニュース・トレンド・記念日）に特化し、AIチャットは右側の便利機能ツールメニュー内へ移設。
- **🎨 設定画面のMaterial Design 3化**:
  - テーマカラー切り替え、地域選択、GitHubリポジトリ設定などの設定画面をM3デザインに刷新。

## 📥 インストール・ダウンロード方法

### 1. GitHub Releasesからダウンロード
1. 本リポジトリの **[Releases](https://github.com/dkym-123a456a7890/Andoroid-dashboard_forOLD/releases)** ページを開きます。
2. 最新のリリース（例: `v1.2`）の **Assets** から `app-debug.apk` をダウンロードします。
3. Android端末でファイルを開き、画面の指示に従ってインストールしてください。

### 2. アプリ内からの自動アップデート
アプリがすでにインストールされている場合は、時計パネル左上の **「更新」** アイコンをタップするだけで、最新版の確認・ダウンロード・インストールが自動で行われます。

## 🛠️ GitHub Actions による自動ビルド

本リポジトリは GitHub Actions（`.github/workflows/android-ci.yml`）が設定されており、タグ付きリリースを作成すると自動的にAPKがビルドされてReleasesに添付されます。

### 新しいバージョンをリリースする手順：
1. GitHubの **Releases** ページで **「Draft a new release」** をクリックします。
2. タグ名に `v1.2`（または次のバージョン番号）を指定します。
3. タイトルと更新内容を入力し、**「Publish release」** をクリックします。
4. 数分待つと GitHub Actions が自動でAPKをビルドし、そのリリースページに添付されます。
